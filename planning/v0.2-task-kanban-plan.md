# Rencana Pelaksanaan Fitur Task Management & Kanban Board (v0.2)

Document Created At: 2026-08-04

---

## 1. Ringkasan Tujuan
Mengimplementasikan fitur **Task Management & Kanban Board (v0.2)** sesuai dengan dokumen spesifikasi `Rencana Sistem Project Management.txt`. Fitur ini memungkinkan pengguna untuk mengelola tugas dalam sebuah proyek dengan antarmuka Kanban Board interaktif yang mendukung Drag & Drop.

---

## 2. Rincian Implementasi

### Tahap 1: Database & Data Modeling (`packages/database`)
* **Edit Schema (`schema.prisma`)**:
  * Tambahkan Enum `TaskStatus`: `BACKLOG`, `TODO`, `IN_PROGRESS`, `REVIEW`, `DEPLOY`, `DONE`.
  * Tambahkan Enum `TaskPriority`: `LOW`, `MEDIUM`, `HIGH`, `URGENT`.
  * Buat Model `Task`:
    * `id`, `title`, `description`, `status`, `priority`, `dueDate`, `position` (float/int untuk ordering DnD).
    * `projectId` (relasi ke `Project`).
    * `assigneeId` (relasi opsional ke `User`).
    * `createdById` (relasi ke `User`).
  * Buat Model `TaskLabel`, `TaskChecklist`, dan `TaskComment` (opsional / bertahap).
* **Eksekusi Prisma**:
  * `bun x prisma migrate dev --name add_task_models --schema=packages/database/prisma/schema.prisma`
  * `bun x prisma generate --schema=packages/database/prisma/schema.prisma`

---

### Tahap 2: Backend API (`apps/api/src/app/task/`)
Buat modul feature-based `task` di backend dengan struktur:
* `schema.ts`: TypeBox schema (`@sinclair/typebox`) untuk validasi request Fastify (Create/Update Task, Reorder Task, Get Task list per Project).
* `service.ts`: Query Prisma untuk CRUD Task, pembaruan urutan status (Drag & Drop position update).
* `controller.ts`: Handler HTTP request Fastify.
* `routes.ts`: Definisi endpoint RESTful:
  * `GET /api/projects/:projectId/tasks`
  * `POST /api/projects/:projectId/tasks`
  * `PATCH /api/tasks/:id`
  * `PATCH /api/tasks/:id/reorder` (untuk DnD status/posisi)
  * `DELETE /api/tasks/:id`
* Registrasi route pada `apps/api/src/app/route.ts`.

---

### Tahap 3: Frontend UI (`apps/web/src/features/task/` & `apps/web/src/features/project/`)
* **API Client & Custom Hooks**:
  * Tambahkan API fetcher dan TanStack Query hooks (`useTasks`, `useCreateTask`, `useUpdateTaskStatus`).
* **Komponen UI**:
  * `KanbanBoard`: Rendering 6 kolom status (`BACKLOG`, `TODO`, `IN_PROGRESS`, `REVIEW`, `DEPLOY`, `DONE`).
  * `KanbanColumn`: Komponen droppable untuk memuat task cards.
  * `TaskCard`: Card item yang draggable menampilkan title, priority, assignee, due date, dan label badges.
  * `TaskDialog`: Modal form untuk membuat/mengedit task baru.
* **Integrasi DnD Kit**:
  * Integrasikan `@dnd-kit/core`, `@dnd-kit/sortable`, dan `@dnd-kit/utilities`.
  * Optimistic UI update saat user men-drag card ke kolom lain sebelum request API selesai.
